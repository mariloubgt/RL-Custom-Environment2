\subsection{Training Pipelines}

\subsubsection{A2C Training Process}

\begin{enumerate}
    \item \textbf{Initialization:}
    \begin{itemize}
        \item Create environment and agent
        \item Initialize Actor-Critic network with random weights
        \item Set hyperparameters (learning rate, discount factor, value/entropy coefficients)
        \item Optionally resume from checkpoint
    \end{itemize}
    \item \textbf{Episode Loop:}
    \begin{enumerate}
        \item Reset environment and agent episode buffer
        \item Collect trajectory:
        \begin{itemize}
            \item Select action using current policy (with exploration)
            \item Execute action in environment
            \item Store state, action, log probability, value estimate, reward, done flag
        \end{itemize}
        \item Train on collected episode:
        \begin{itemize}
            \item Compute discounted returns (TD($\lambda$) or Monte Carlo)
            \item Compute advantages (returns - value estimates)
            \item Normalize advantages for stability
            \item Update policy network (policy gradient with entropy bonus)
            \item Update value network (value function regression)
        \end{itemize}
        \item Log metrics (reward, length, loss, entropy)
        \item \textbf{Periodic Evaluation} (every N episodes, default 200):
        \begin{itemize}
            \item Run evaluation episodes without exploration
            \item Compute metrics: average reward, destruction rate, success rate, impact rate
            \item Track best performing model
            \item Save best model if performance improved
        \end{itemize}
    \end{enumerate}
    \item \textbf{Checkpointing:}
    \begin{itemize}
        \item Save model every N episodes (configurable)
        \item Save best model when evaluation improves
        \item Save final model at end of training
        \item Generate training curves (rewards, losses, entropy, hit rates)
    \end{itemize}
\end{enumerate}

\subsubsection{DQN Training Process}

\begin{enumerate}
    \item \textbf{Initialization:}
    \begin{itemize}
        \item Create environment and agent
        \item Initialize Q-network and target network (identical weights)
        \item Initialize replay buffer (experience replay)
        \item Set $\epsilon$-greedy exploration schedule
    \end{itemize}
    \item \textbf{Episode Loop:}
    \begin{enumerate}
        \item Reset environment
        \item Step loop:
        \begin{itemize}
            \item Select action using $\epsilon$-greedy policy
            \item Execute action in environment
            \item Store experience tuple $(s, a, r, s', done)$ in replay buffer
            \item Sample random batch from replay buffer (if buffer sufficient)
            \item Compute Q-learning targets
            \item Update Q-network using TD error
            \item Update target network periodically (soft or hard update)
        \end{itemize}
        \item Decay $\epsilon$ (exploration rate)
        \item Log metrics
        \item \textbf{Periodic Evaluation} (every N episodes, default 200):
        \begin{itemize}
            \item Run evaluation episodes with $\epsilon = 0$ (no exploration)
            \item Compute performance metrics
            \item Track and save best model
        \end{itemize}
    \end{enumerate}
    \item \textbf{Evaluation:}
    \begin{itemize}
        \item Periodic evaluation episodes (no exploration)
        \item Track best model based on success rate, destruction rate, and average reward
        \item Save best model checkpoint
    \end{itemize}
\end{enumerate}

\subsection{Evaluation During Training}

Both A2C and DQN training scripts include periodic evaluation to monitor agent performance:

\begin{itemize}
    \item \textbf{Frequency:} Configurable (default: every 200 episodes)
    \item \textbf{Episodes:} Configurable number of evaluation episodes (default: 20)
    \item \textbf{Exploration:} Disabled during evaluation (deterministic policy)
    \item \textbf{Metrics Computed:}
    \begin{itemize}
        \item Average reward and standard deviation
        \item Destruction rate: percentage of asteroids destroyed
        \item Success rate: percentage of episodes with positive reward
        \item Impact rate: percentage of episodes ending with planet impact
        \item Hit rate: percentage of shots that hit asteroids
    \end{itemize}
    \item \textbf{Best Model Tracking:} Automatically saves best model based on:
    \begin{enumerate}
        \item Success rate (primary criterion)
        \item Destruction rate (secondary criterion)
        \item Average reward (tertiary criterion)
    \end{enumerate}
\end{itemize}
